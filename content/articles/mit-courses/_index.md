# MIT OCW Courses

Here is a graph of all MIT OCW (OpenCourseWare) courses that I could find.

The image is an SVG file created using [draw.io](https://www.drawio.com/). You
can download the [draw.io desktop version
here](https://github.com/jgraph/drawio-desktop/releases). You can open the file
in draw.io if you want to edit it, or open it in a browser if you only want to
view it (as it's an SVG).

Normally, I would make it a `drawio.png`, but I need the links to be clickable, so `drawio.svg` makes more sense.

You can find a static list of all courses [here](./courses).
